## 项目概述

面向【公司名称】发布流程繁琐、内部知识来源分散、代码仓库规模达 300+ GB，以及通用 Copilot 在相关业务问答中准确性不足、代码相关问题响应较慢的问题，独立开发定制化 RAG 知识助手，负责业务资料组织、检索策略优化与 Copilot 工作流集成。相比传统 Copilot 对相关问题的搜索与回答，问题回答准确性提升 **28%**，响应速度提升 **62%**，降低工程师查找和核对资料的成本，已供中国、美国及印度多个团队使用。

## 技术栈

Python / MCP / ChromaDB / BM25 / Dense Embedding / RRF / Cross-Encoder / Streamlit

## 核心工作

### 业务定制检索
针对【公司名称】组件名等精确术语与自然语言问题并存的特点，结合 BM25 与 Dense 召回，经 RRF 融合及可选重排组织结果；通过集合、来源与元数据过滤限定业务资料范围。

### 文档摄取与溯源
围绕团队业务文档构建加载、分块、元数据处理、Embedding 与索引写入流程，以内容指纹跳过重复摄取，返回来源文件、页码和片段，支持发布资料与业务知识核对。

### Copilot 集成与可靠性
通过 MCP 暴露知识查询、集合与文档摘要接口，将阻塞调用移入线程，记录查询 Trace；检索或重排异常时降级，支撑知识助手在研发工作流中的使用与问题定位。

### 领域查询与版本约束
扩展模块化查询处理与元数据过滤，解析【公司名称】内部缩写、组件及分支版本，将受控术语扩展和适用范围约束接入原有 BM25 + Dense 双路召回，保留 RRF 融合与重排，减少术语歧义和跨版本干扰。

### 结构分块与证据展开
扩展 Loader、Splitter 及片段元数据，保留发布文档的标题层级、前置条件与原文引用关系，采用小片段召回、父章节按需展开的方式，在上下文预算内补齐流程依据，并通过 MCP 返回可核对的原文引用。

### 领域评测与消融实验
构建覆盖术语歧义、版本冲突、流程依赖及无答案问题的评测集，固定语料与候选预算，对术语扩展、版本过滤、分块及重排进行消融；结合 Recall@k、MRR、版本正确率与 Copilot 端到端引用及步骤完整性评估质量—延迟取舍。

## 简历投递要点（一句话版）

> 独立开发面向 300+ GB 内部代码与发布资料的定制化 RAG 知识助手，基于 MCP 集成进 Copilot 工作流，通过 BM25 + Dense 双路召回、RRF 融合与 Cross-Encoder 重排、结构化分块与元数据过滤，使回答准确性提升 28%、响应速度提升 62%。
